# תיק עבודות — מדריך הפעלה ופריסה

אתר סטטי (HTML/CSS/JS בלבד). אין backend, אין תהליך build, אין תלויות להתקין.

---

## 1. מה נמצא איפה

```
portfolio/
├── index.html      ← טקסטים אישיים: שם, תפקיד, אודות, פרטי קשר
├── styles.css      ← עיצוב (צבעים ופונטים בראש הקובץ, תחת :root)
├── app.js          ← לוגיקה — בדרך כלל אין צורך לגעת
├── data/videos.js  ★ רשימת הסרטונים — הקובץ היחיד שתערוך באופן שוטף
└── assets/cv.pdf   ← קורות החיים שלך (צריך להוסיף)
```

---

## 2. מה למלא לפני ההעלאה

### א. `index.html`
כל המקומות לעריכה מסומנים בהערות `▼ ... ▼`. עברו עליהם לפי הסדר:

| מה | איפה |
|---|---|
| שם, תיאור, תגיות שיתוף | בתוך `<head>` — `<title>` ותגי `og:` |
| שם בהירו | `<h1 class="hero__name">` — ה-`<br>` שובר שורה בין שם פרטי למשפחה |
| התפקיד המבוקש | `<p class="hero__role">` |
| משפט על עצמך | `<p class="hero__pitch">` |
| פסקאות אודות | `<div class="about__body">` |
| מייל, לינקדאין, אינסטגרם | `<ul class="contact__list">` — שנו גם את ה-`href` וגם את הטקסט |
| שם בפוטר | `<footer>` |

> בקישור המייל שנו את **שני** המקומות: `href="mailto:..."` וגם הטקסט המוצג.

### ב. קורות חיים
שימו את הקובץ בנתיב `assets/cv.pdf` (בדיוק בשם הזה). מחקו את קובץ ההסבר שנמצא שם.

### ג. סרטונים — `data/videos.js`
1. העלו את הסרטון ליוטיוב כ-**Unlisted / לא רשום**.
2. קחו את המזהה מהקישור — 11 התווים שאחרי `?v=`:
   `https://www.youtube.com/watch?v=`**`dQw4w9WgXcQ`**
3. הדביקו אותו בשדה `youtubeId` במקום `REPLACE_ME_0X`.

כל עוד לא הוזן מזהה תקין, הכרטיס מציג מציין־מיקום מעוצב — האתר נראה שלם גם באמצע התהליך.

**להוספת סרטון חדש** — העתיקו בלוק שלם והוסיפו לרשימה:
```js
{
  youtubeId: "dQw4w9WgXcQ",
  title: "כותרת הסרטון",
  description: "מה עשיתי — כתיבה/צילום/עריכה, ומה היה האתגר.",
  roles: ["כתיבה", "עריכה"],     // רק מהערכים: "כתיבה" · "צילום" · "עריכה"
  context: "עבור מי / לאיזה צורך",
},
```
המסננים בראש הגלריה נבנים אוטומטית מהשדה `roles`.

### ד. לראות את האתר לפני ההעלאה
דאבל־קליק על `index.html`. זהו. (זו הסיבה שהנתונים יושבים בקובץ `.js` ולא ב-`.json` — דפדפנים חוסמים קריאת JSON מקובץ מקומי.)

## 3. פריסה ל-GitHub Pages

התוצאה: כתובת קבועה, חינם, פעילה 24/7, בלי כרטיס אשראי.

### שלב 1 — חשבון GitHub
1. היכנסו ל-<https://github.com/signup>
2. מייל → סיסמה → **שם משתמש** (חשוב: הוא יופיע בכתובת האתר, בחרו משהו מקצועי כמו `israel-israeli`)
3. אשרו את המייל שיישלח אליכם.

*כבר יש חשבון? דלגו לשלב 2.*

### שלב 2 — יצירת ריפו
1. <https://github.com/new>
2. **Repository name**: `portfolio`
3. **Public** (חובה — Pages בטייר החינמי עובד רק על ריפו ציבורי)
4. אל תסמנו כלום ב-"Initialize this repository"
5. **Create repository**

### שלב 3 — העלאת הקבצים

**האפשרות הפשוטה — גרירה בדפדפן:**
1. בעמוד הריפו החדש לחצו **uploading an existing file**
2. פתחו את תיקיית `portfolio` במחשב, סמנו הכל (`Ctrl+A`) וגררו לחלון הדפדפן
   *(גררו את **תוכן** התיקייה, לא את התיקייה עצמה — `index.html` חייב לשבת בשורש הריפו)*
3. המתינו שכל הקבצים יעלו, כולל התיקיות `data` ו-`assets`
4. למטה: **Commit changes**

**האפשרות דרך Git** (אם מותקן אצלכם):
```bash
git init -b main
git add .
git commit -m "Portfolio site"
git remote add origin https://github.com/USERNAME/portfolio.git
git push -u origin main
```
החליפו `USERNAME` בשם המשתמש שלכם. הפקודות רצות מתוך תיקיית `portfolio`.

### שלב 4 — הפעלת Pages
1. בריפו: **Settings** (בסרגל העליון)
2. בתפריט הצד: **Pages**
3. תחת *Build and deployment* → **Source**: `Deploy from a branch`
4. **Branch**: `main`, תיקייה: `/ (root)` → **Save**
5. המתינו 1–2 דקות ורעננו. תופיע הכתובת:

```
https://USERNAME.github.io/portfolio/
```

זו הכתובת לשלוח למגייס.

> **הפריסה הראשונה לוקחת עד ~2 דקות.** אם מופיע 404 — המתינו רגע ורעננו עם `Ctrl+F5`.

## 4. לעדכן סרטון אחרי שהאתר באוויר

בלי להוריד כלום למחשב:

1. בריפו ב-GitHub → `data` → `videos.js`
2. אייקון העיפרון ✏️ (Edit this file)
3. הדביקו את המזהה במקום `REPLACE_ME_0X`
4. למטה → **Commit changes** → **Commit changes** שוב

האתר מתעדכן לבד תוך כדקה. (לראות התקדמות: לשונית **Actions** בריפו.)

## 5. תקלות נפוצות

| תופעה | הסיבה |
|---|---|
| 404 בכתובת האתר | `index.html` לא בשורש הריפו — הועלתה התיקייה במקום תוכנה |
| האתר עולה בלי עיצוב | `styles.css` לא הועלה, או השם שונה |
| כל הכרטיסים ריקים | `data/videos.js` חסר. בדקו שהתיקייה `data` קיימת בריפו |
| הסרטון לא מתנגן | הסרטון הוגדר **Private** ולא **Unlisted** — Private חוסם הטמעה |
| כפתור קו"ח מוביל ל-404 | הקובץ חייב להיות בדיוק `assets/cv.pdf` (אותיות קטנות) |
| שינוי לא מופיע | רענון עם `Ctrl+F5` (הדפדפן שומר גרסה במטמון) |

## 6. שינוי צבעים ופונטים

בראש `styles.css`, תחת `:root`:

```css
--paper:  #FBF8F2;   /* רקע */
--ink:    #17150F;   /* טקסט */
--accent: #A63D2F;   /* צבע ההדגשה — כותרות משנה, קווים, hover */
```

הפונטים — `Frank Ruhl Libre` לכותרות ו-`Assistant` לגוף הטקסט — נטענים מ-Google Fonts ב-`index.html`. להחלפה: בחרו פונט עברי ב-<https://fonts.google.com/?subset=hebrew>, החליפו את תגית ה-`<link>` ואת המשתנים `--serif` / `--sans`.
